# shadcn/ui

Use shadcn/ui as the primary UI component foundation.

## Prefer Existing Components

Before building a custom UI primitive, check shadcn.

Examples:

Button
Input
Textarea
Select
Tabs
Dialog
DropdownMenu
Tooltip
Popover
Command
Slider
Switch
Progress
ScrollArea

## Rules

Do not duplicate shadcn primitives unnecessarily.

Customize through:

- composition
- variants
- Tailwind classes
- design tokens

Avoid modifying generated primitive behavior without a clear reason.

## Styling

Prefer Tailwind utilities.

Avoid arbitrary inline styles unless required for dynamic values.

Keep component APIs simple.
