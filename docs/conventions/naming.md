# Naming

All code identifiers use English.

## Files

Use kebab-case.

Good:

image-studio.tsx
tool-header.tsx
file-dropzone.tsx

## Components

Use PascalCase.

ImageStudio
ToolHeader
FileDropzone

## Variables

Use camelCase.

outputFormat
originalSize
processedFile

## Tool IDs

Use lowercase English identifiers.

json
image
audio
jwt
timestamp
base64
uuid
vietnamese-slug
