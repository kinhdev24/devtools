# Localization

Supported UI languages:

- English: en
- Vietnamese: vi

English is the default language.

## Localize

Only localize user-facing content:

- Titles
- Descriptions
- Buttons
- Labels
- Empty states
- Errors
- Tooltips

## Never Localize

- Routes
- Tool IDs
- Variable names
- File names
- Component names
- Config keys
- API fields
- Internal identifiers

## Example

Route:

/image

English UI:

Image Studio
Convert images locally.

Vietnamese UI:

Xử lý hình ảnh
Chuyển đổi hình ảnh ngay trên thiết bị.

The route remains:

/image
