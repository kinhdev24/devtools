# Design Principles

DevTools is a developer workbench.

Optimize for:

1. Speed
2. Clarity
3. Low visual noise
4. Keyboard-first interaction
5. Developer familiarity
6. Local-first trust

## Prefer

- Flat UI
- Compact layout
- Neutral colors
- Subtle borders
- Clear hierarchy
- Functional interfaces

## Avoid

- Glassmorphism
- Neon
- Cyberpunk
- Large gradients
- Giant cards
- Excessive shadows
- Decorative animations

## Direction

Raycast speed

- Linear clarity
- VS Code familiarity
