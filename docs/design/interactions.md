# Interactions

Optimize for minimum actions.

Ideal:

Paste → Result

or:

Drop → Convert → Download

## Command Palette

Shortcut:

⌘ K
Ctrl K

Support:

- Tool search
- Recent tools
- Keyboard navigation

## Copy

Use:

Copy → Copied

Do not show a modal.

## Errors

Good:

Invalid JSON at line 14, column 8.

Bad:

Something went wrong.

100–200ms
