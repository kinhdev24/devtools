# AI Agent Checklist

## Before

- Read the relevant feature document.
- Read design rules.
- Check existing components.
- Check tool registry.
- Determine client/server boundary.

## During

- Use English code identifiers.
- Use English routes.
- Localize user-facing text.
- Support en and vi.
- Prefer local processing.
- Reuse shadcn components.
- Reuse project components.
- Support dark and light themes.
- Preserve SSR.
- Lazy-load heavy tool dependencies.

## Before Completion

Verify:

- Desktop
- Mobile
- Dark mode
- Light mode
- English
- Vietnamese
- Keyboard navigation
- Error states
- Copy actions
- Download actions
- No unexpected server requests
- No unexpected file uploads
