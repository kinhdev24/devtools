# Adding a Tool

Before adding a new tool:

1. Check whether it belongs inside an existing Studio.

2. Choose:
   - English ID
   - English route
   - English code names

3. Add:
   - Tool registry entry
   - English translations
   - Vietnamese translations
   - Feature documentation

4. Decide execution location:
   - Client when possible
   - Server Function only when necessary

5. Reuse existing components.

6. Add search aliases.

7. Verify with the AI Agent Checklist.
