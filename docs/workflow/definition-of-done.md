# Definition of Done

A feature is complete when:

## Functionality

- Core workflow works.
- Errors are handled.
- Loading/progress states work.

## UI

- Matches existing design.
- Uses existing components.
- Works in light and dark themes.
- Works on desktop and mobile.

## Localization

- English UI works.
- Vietnamese UI works.
- Routes remain English.

## Architecture

- SSR remains functional.
- Client processing is used when appropriate.
- Server Functions are used only when necessary.

## Privacy

- No unexpected uploads.
- No unnecessary persistence.
- Local processing claims are accurate.

## Performance

- Heavy dependencies are lazy-loaded.
- Long processing does not unnecessarily block the UI.
