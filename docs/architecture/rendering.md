# Rendering

TanStack Start SSR remains enabled.

## SSR Responsibilities

Use SSR for:

- Application shell
- Initial page rendering
- SEO metadata
- Static tool information
- Navigation structure

## Client Responsibilities

Use client-side execution for:

- JSON transformations
- JWT decoding
- UUID generation
- Base64 utilities
- Image conversion
- Audio conversion
- Interactive editors
- File processing

## Rule

SSR renders the tool page.

The browser performs the tool operation whenever possible.
