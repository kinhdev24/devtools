# Timestamp

Local-first timestamp debugger powered by Day.js. It auto-detects Unix seconds,
milliseconds, microseconds, nanoseconds, ISO 8601, RFC dates, and common date
formats. Users can override ambiguous units, compare timezones, inspect calendar
facts, shift an instant, and copy runtime-specific snippets.

All parsing, formatting, duration arithmetic, relative-time calculation, and
timezone comparison run in the browser. The feature does not use loaders or
server functions.
